Build a playable futuristic racing game in the browser: a sleek racing craft speeds along an illuminated track that winds through a neon city at night. Include a start screen, keyboard controls (arrow keys or WASD, space to boost), a lap timer and lap counter, a speed readout, and a finish screen with the race time. Make it feel fast and look polished.
Save everything as a single self-contained file named index.html in the current directory (inline CSS/JS; you may load three.js from https://unpkg.com/three@0.170.0 as an ES module import map if needed). Do it in one go, do not ask questions.
