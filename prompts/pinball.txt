Build a playable 3D pinball table in the browser. The player launches the ball with a plunger and controls the left and right flippers with the keyboard. Include bumpers that light up and push the ball, ramps or lanes, a score display, three balls per game, and a game-over screen with the final score. The table should look like a real, colourful pinball machine.
Save everything as a single self-contained file named index.html in the current directory (inline CSS/JS; you may load three.js from https://unpkg.com/three@0.170.0 as an ES module import map if needed). Do it in one go, do not ask questions.
