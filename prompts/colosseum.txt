Build an interactive 3D recreation of the Roman Colosseum in the browser that the user can explore from different angles. Model the arena's tiers of arches, the arena floor and the underground hypogeum, with daylight and shadows. Let the user orbit and zoom freely, and add buttons that fly the camera to a few named viewpoints (aerial view, arena floor, top tier) with short captions about each.
Save everything as a single self-contained file named index.html in the current directory (inline CSS/JS; you may load three.js from https://unpkg.com/three@0.170.0 as an ES module import map if needed). Do it in one go, do not ask questions.
